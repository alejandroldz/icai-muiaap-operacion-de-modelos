TRANSCRIPCIÓN DE RESPALDO — S7 HTTP/REST CLIENTS
Los request_id se han abreviado. Esta evidencia se usa solo si no puede
arrancarse la API local.

=== GET /health ===
> GET /health HTTP/1.1
> Host: 127.0.0.1:8000
> Accept: application/json

< HTTP/1.1 200 OK
< Content-Type: application/json; charset=utf-8
< X-Request-Id: req_health

{"status":"ok","service":"pump-maintenance-prediction","model_status":"ready","model_version":"pump-risk-1.0.0","request_id":"req_health"}

=== POST válido ===
> POST /v1/predictions HTTP/1.1
> Host: 127.0.0.1:8000
> Accept: application/json
> Content-Type: application/json
>
> {"machine_id":"pump-017","measurements":{"temperature_c":91.2,"vibration_mm_s":8.4,"pressure_bar":4.7,"runtime_hours":12840}}

< HTTP/1.1 200 OK
< Content-Type: application/json; charset=utf-8
< X-Request-Id: req_success

{"machine_id":"pump-017","prediction":{"label":"maintenance_required","risk_score":0.85},"model_version":"pump-risk-1.0.0","request_id":"req_success"}

=== POST con JSON válido que incumple el contrato ===
> POST /v1/predictions HTTP/1.1
> Content-Type: application/json
>
> {"machine_id":"pump-017","measurements":{"temperature_c":91.2,"vibration_mm_s":"alta","pressure_bar":4.7,"runtime_hours":12840}}

< HTTP/1.1 422 Unprocessable Entity
< Content-Type: application/json; charset=utf-8
< X-Request-Id: req_validation

{"error":{"code":"validation_error","message":"JSON is valid but violates the input contract","fields":[{"field":"measurements.vibration_mm_s","message":"must be a number"}]},"request_id":"req_validation"}

=== POST con JSON truncado ===
> POST /v1/predictions HTTP/1.1
> Content-Type: application/json
>
> {"machine_id":"pump-017","measurements":{

< HTTP/1.1 400 Bad Request
< Content-Type: application/json; charset=utf-8
< X-Request-Id: req_bad_json

{"error":{"code":"invalid_json","message":"The request body is not valid JSON"},"request_id":"req_bad_json"}

< HTTP/1.1 503 Service Unavailable
< Content-Type: application/json
< Retry-After: 10

{"error":{"code":"model_unavailable","message":"Model is loading"},"request_id":"req_unavailable"}
